# 智能打卡小程序

一键启动 → **[点击启动后端](start.bat)**（Windows）或 `bash start.sh`（Linux/Mac）

---

## 项目结构

```
dutyapp/
├── start.bat              ← 一键启动后端（Windows）
├── start.sh               ← 一键启动后端（Linux/Mac）
├── smart_checkin.sql      ← 数据库建表脚本
├── test-cases.md          ← 测试用例文档
├── backend/               ← Spring Boot 后端
└── miniprogram/           ← 微信小程序前端
```

## 快速开始

### 1. 初始化数据库

**全新安装** — 执行 `smart_checkin.sql` 建库建表：

```sql
source smart_checkin.sql
```

**从 v1 升级** — 执行增量迁移脚本（新增 `users.gender`、`activities.invite_enabled`、`user_subscriptions` 表）：

```sql
source migration_v2_features.sql
```

> ⚠️ 迁移脚本只能对 v1 库执行一次；重复执行会因字段已存在而报错。

### 2. 启动后端

**Windows** — 双击 `start.bat`

**Linux/Mac** — 终端运行 `bash start.sh`

**手动启动**：

```bash
cd backend
mvn spring-boot:run
```

启动后访问 `http://localhost:8080`

### 3. 配置修改

编辑 `backend/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    username: root      # 改为你的MySQL用户名
    password: root      # 改为你的MySQL密码

wechat:
  app-id: your-app-id       # 改为你的小程序AppID
  app-secret: your-app-secret  # 改为你的小程序AppSecret

aes:
  secret-key: your-secret-key-32-chars!!  # 改为你的安全密钥
```

### 4. 打开小程序

微信开发者工具导入 `miniprogram/` 目录，修改 `utils/request.js` 中的 `BASE_URL` 为你的后端地址。

## 技术栈

| 模块 | 技术 |
|------|------|
| 后端 | Spring Boot 2.7 + MyBatis-Plus 3.5 + JWT + POI |

| 前端 | 微信小程序原生框架 |
| 安全 | AES-256身份证加密 + JWT鉴权 |
